# Security

## Supported versions

Only the latest release gets security fixes. Please update first (Kural checks once a day, or Help > Check for Updates).

## Reporting a vulnerability

Please don't open a public issue for a security problem.

- Use GitHub's private reporting: https://github.com/adithyakumarcr/kural/security/advisories/new
- Or email adithyakumarcr@hotmail.com.

What to expect: an answer within 7 days, and a fix or a workaround within 90 days. If you like, you're credited in the
release notes.

## Scope

Kural's own code (the extension, the build scripts, the updater, the release workflow). Problems in VSCodium, VS Code or
Chromium belong to those projects; Kural ships their fixed version in its next release.

Releases are signed: see [docs/release-signing.md](docs/release-signing.md) for how to verify a download.
