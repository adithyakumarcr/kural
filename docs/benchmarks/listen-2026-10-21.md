# Listen: voice engine spike, 21 Oct 2026

Plan: `docs/superpowers/plans/2026-10-21-listen.md` Task 1. Throwaway code: `scripts/listen-spike/` (models and samples in
its `out/`, not committed). Machine: 16 threads, 30 GB, Ubuntu; every run inside Kural's own program
(`ELECTRON_RUN_AS_NODE=1 /usr/share/kural/kural --no-liftoff`), the "4-core" runs under `taskset -c 0-3` with 3 threads
(the plan's `availableParallelism() - 1`).

## Runtime

| Runtime | Supertonic 3, 13-word sentence (4.7 s of audio) | Notes |
|---|---|---|
| onnxruntime-web 1.30 (WebAssembly), 1 thread | 3.30 s | |
| onnxruntime-web 1.30, 8 threads | 3.21 s | Starts its worker threads, but CPU stays at 99%: no speed-up under Node |
| onnxruntime-node 1.23.2 (native, Node-API), 1 thread | 1.12 s | Loads and runs inside Kural's program with no rebuild |
| onnxruntime-node 1.23.2, 4 threads | 0.63 s | |

So the runtime is **onnxruntime-node** (ladder step 3): about 3× faster than WebAssembly on one thread, and it uses
threads. Its CPU-only files per platform: Linux x64 `libonnxruntime.so.1` 32.7 MB + `onnxruntime_binding.node` 0.4 MB;
macOS arm64 `libonnxruntime.1.23.2.dylib` 35.7 MB + binding 0.2 MB; Windows x64 `onnxruntime.dll` 23.6 MB + binding
0.3 MB (+ `DirectML.dll` 18.5 MB if the binding needs it: to check). The npm package is 258 MB unpacked (every platform,
CUDA), so Kural would publish the per-platform files on its own release. Not checked: macOS loading it (signing), Windows.

## A real walkthrough

Haiku wrote a 183-word walkthrough of a real Kural answer (`out/walkthrough.txt`), spoken sentence by sentence with a
0.18 s pause (as Listen would), on 4 cores:

| Sample | First sentence ready | All made in | Audio |
|---|---|---|---|
| Supertonic 3 F1 / F2 / M1 / M2 (with `<laugh>` and `<breath>`) | 0.85–0.95 s | 16–17 s | 66–71 s |
| Supertonic 3 F1 without tags | 0.90 s | 16.4 s | 70.1 s |
| Kokoro fp16 af_heart / am_michael / bm_george | 0.76–0.84 s | 18–20 s | 72–81 s |
| Piper ljspeech | 0.12 s | 2.4 s | 69.9 s |

Expression tags: the model card lists only `<laugh>`, `<breath>` and `<sigh>` (it says 10 exist; no list was found). The
tagged sample is 0.7 s longer than the untagged one: whether that is a laugh or the word read out has to be heard.
