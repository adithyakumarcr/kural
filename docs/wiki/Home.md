# Kural Code Editor

Kural is a code editor with an AI assistant built in. It is [VSCodium](https://vscodium.com) (the open-source build of
VS Code), so everything you know from VS Code works the same: extensions, themes, settings, the terminal, Git.

Kural's AI comes from one of two places, or both:

- **Claude.** Anthropic's Claude models, through Claude Code and your Claude plan. No API key, nothing extra to pay.
- **Your own model.** A model on your computer through [Ollama](https://ollama.com). No account, no internet: your code
  never leaves your computer.

## Missing something?

Kural's chat knows these features: ask it "can Kural …?" or "how do I …?". If Kural can't do what you need,
[ask for it as a feature](https://github.com/adithyakumarcr/kural/issues/new?template=feature_request.yml). Found a bug?
[Report it](https://github.com/adithyakumarcr/kural/issues/new?template=bug_report.yml).
