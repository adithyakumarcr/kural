# Ask

**Ask** (magnifier icon in the left side bar, **Ctrl+Alt+A**) finds code by describing it: "where is the retry limit
set?", "what sends the welcome email?". Kural searches your project and lists the exact places (`file:line`); click one
to open it.

It uses the chat's model (Claude or [[Your Own Model]]). For plain text search, use VS Code's own search
(**Ctrl+Shift+F**).
