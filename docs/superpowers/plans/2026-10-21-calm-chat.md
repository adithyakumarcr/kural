# Calm Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kural's chat answers become calm and easy to read (Calm reading), the AI's thinking shows as a scrolling timeline, and questions are answered by picking options and pressing Send, with a way to ask about a question first.

**Architecture:** Three new page modules, factories like `media/listen.js`: `media/markdown.js` (Markdown → plain blocks → DOM via `el()`), `media/timeline.js` (the thinking timeline) and `media/choices.js` (pick, then Send; Ask about this question). They load before `media/chat.js`, which wires them in. The backend (`lib/chat/index.js`) learns two new shapes of the `answer` message (with a note, with an ask) and keeps `picks` on user messages; `lib/chat/prompts.js` tells every AI the Markdown conventions; `lib/ai/codex.js` prefers raw reasoning.

**Tech Stack:** Plain JavaScript (no build step, no runtime dependencies), a VS Code webview (CSP with a nonce), Node test scripts (`npm test` runs every `test/*.test.js` through `test/run.js`).

**Spec:** `docs/superpowers/specs/2026-10-21-calm-chat-design.md`

**Mockup (approved):** `docs/superpowers/specs/2026-10-21-calm-chat-mockup.html`: open it in a browser. Its CSS is the
reference for the look (the panel, the timeline, the questions); "from the mockup" below means this file.

## Global Constraints

- No runtime npm dependencies, no build step. Page scripts load as `<script nonce="${nonce}" src="${uri("<file>")}"></script>` in `extension/lib/chat/index.js:761`, before `chat.js`.
- A page module sets `window.KURAL_<NAME> = function (deps) {…}` and, when `typeof module !== "undefined"`, `module.exports` = the same factory (pattern: `extension/media/listen.js`), so tests `require()` it.
- Nothing the AI writes becomes HTML except through `inline()` in `chat.js` (escapes first, then placeholders). Modules build the DOM with the `el()` they're given; never `innerHTML` with AI text.
- No emoji anywhere. Icons are Codicons through `icon(name)`. The page's CSP blocks `style="…"` attributes: style through `el()`'s `style` prop (it sets `cssText`) or classes.
- Every font size is `calc(<n>px * var(--fs, 1))`, like the rest of `chat.css`. Both themes: dark is `:root`, light is `body.vscode-light`. Text at least 4.5:1 on its background, tinted callouts included.
- Exact words: callout labels "Note", "Tip", "Important", "Watch out", "Risk"; timeline tags "Claude's summary", "ChatGPT's summary", "raw"; "Working… N s"; "Worked for N s · …"; "Latest"; above the box "Your answer" … "(press Send)"; box hint "Add a note (optional), then press Send"; ask box "Not sure? Ask about this question" and its button "Ask"; "Updated after your question"; "The question before you asked"; "You answered"; "Skipped"; "Recommended"; "Yes"; "No".
- Exact sizes: headings `#` 16px, `##` 14.5px with a 1px line under it, `###` 13.5px semibold, `####` 13px semibold muted; answer text line-height 1.68; timeline `max-height: 300px`; options: 2–6 items, each at most 120 characters.
- `extension/lib/chat/guide.js` and `docs/wiki/` change with the feature (CLAUDE.md). Release notes go under `## Not released yet` at the top of `RELEASE_NOTES.md` (v1.2.1-beta.1 is tagged). The version stays `1.2.1-beta.1`.
- Branch `feat-calm-chat`; never commit to `main`. Commit only with Adithya's OK for this session.

## Review Focus

1. A running answer ending in half-written syntax (`> [!WARN`, `| a | b`, `- [ `, an unclosed fence) is drawn as text or a plain quote, never throws, and becomes the full element when complete. Test in Task 1.
2. A list after a paragraph with a "?" only earlier ("Why does it fail? Because X. Steps:") stays a plain list: no buttons. Test in Task 2.
3. Options in earlier answers, and in chats opened from History, are never clickable; only the last answer of an idle chat offers buttons. Test in Task 6.
4. A question card is waiting and you type a normal message without picking anything: Send queues it as today and doesn't answer the card. Test in Task 6.
5. A model on this computer streams thousands of words of raw thinking: per frame only the last thought's text changes, the timeline stays at its end while following, nothing else is rebuilt. Test in Task 4.
