# Contributing to Kural

Thanks for helping! The `main` branch is protected, so all changes go through a pull request.

1. Fork the repo (or, with access, make a branch): `git checkout -b my-change`
2. Make your change. Run the tests: `npm test`. Try it: `./install.sh` (Mac or Ubuntu).
3. Push your branch and open a pull request to `main`. Say what you changed and why.
4. The tests run automatically. Adithya reviews the pull request and merges it.

Releases are made only by the maintainer, by tagging `main` (see "Releases" in the README).
