# Ask for a change

Try: “Explain how this project starts” or “Add a search box to this page.”

| Mode | What Kural does |
|---|---|
| Agent | Edits files and asks before commands |
| Auto | Edits files and runs commands |
| Plan | Writes a plan for you to review |
| Ask | Answers without changing files |

Review each file change and choose **Keep** or **Undo**.

To explore another direction, hover a message and choose **Fork from here**. A new chat carries the conversation through that message.
